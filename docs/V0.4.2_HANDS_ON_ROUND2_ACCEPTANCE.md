# v0.4.2 Hands-on Round 2 — acceptance matrix

This matrix is additive to every previous native/release gate. Round 2 may not delete a historical acceptance item to make a new UX pass green.

## A. Host integration and context intent

- A1 Tool group name is obtained from `Texts.ToolGroupUtilityName`; no literal English/Japanese group display text is used.
- A2 exact YMM4 4.55.1.1 places the Tool under the same built-in Utility group as Explorer/Browser/Plugin Portal/Notepad.
- A3 Item pointer input transitions to Selection context only after a non-empty post-click selection is available.
- A4 re-clicking the already-selected Item still yields Selection context.
- A5 blank Timeline pointer input transitions to Generic even though YMM4 preserves the old selection.
- A6 ruler click transitions to Generic.
- A7 ruler drag produces at most the intended context switch and repeated CurrentFrame changes do not repeatedly churn Set state.
- A8 keyboard-only CurrentFrame movement keeps the current context.
- A9 playback CurrentFrame movement keeps the current context.
- A10 programmatic CurrentFrame movement keeps the current context.
- A11 unknown pointer routes keep the current context.
- A12 router subscriptions are removed on Tool/view/timeline lifecycle changes; no duplicate handlers accumulate.

## B. Unified placement surface

- B1 the normal surface presents Set -> tile, not Intent -> Set -> tile.
- B2 Selection context shows only targeted Sets matching the current selection contract.
- B3 Generic context shows Style/Quick-Drop Sets.
- B4 switching Generic <-> Selection does not mutate Timeline or settings by itself.
- B5 one applicable Set hides redundant Set-selection UI.
- B6 several Sets remain directly switchable without reopening Settings.
- B7 targeted tile execution still uses the existing relative planning/preflight path.
- B8 generic tile execution still uses the existing QuickDrop planner/native Undo path.
- B9 adapter/UI code does not duplicate placement geometry.
- B10 no Item selection is silently cleared merely to display Generic context.

## C. Set-first Settings

- C1 common Settings begins with direct target choices including 汎用 and common Item types.
- C2 the common path has no separate "やりたいこと / Intent" selector.
- C3 `IntentPalette.Name` is the targeted Set name shown to the user.
- C4 old serialized Intent values remain intact through load/save unless the user performs a separately-defined compatibility edit.
- C5 creating a new targeted Set does not ask the user to invent both an Intent and Set name.
- C6 Voice setup does not expose the full runtime type matrix before normal Set details.
- C7 mixed/multi-type targeting remains available under Advanced.
- C8 built-in Item names remain user-facing Japanese.
- C9 Settings navigation/editing remains Timeline zero-write.
- C10 staged Save/Discard/external-change protection remains intact.

## D. Structured "どう置く？"

- D1 the primary relation description is rendered as one understandable sentence/phrase flow.
- D2 editable sentence tokens map only to finite supported enum/model values.
- D3 changing a sentence token immediately updates the human-readable result without mutating Timeline.
- D4 invalid combinations are absent or disabled rather than accepted then guessed.
- D5 numeric offsets/gaps/tolerance/layer bounds are under `細かく調整`.
- D6 targeted saved output is semantically equivalent to the previous underlying relation fields.
- D7 generic sentence exposes only QuickDrop semantics actually supported by the generic backend.
- D8 no free-form natural-language parsing, LLM or network dependency is introduced.
- D9 saved/reloaded sentence state reconstructs from model values, not cached prose.
- D10 hidden irrelevant invalid numeric text does not block a mode where that value is unused, preserving existing progressive validation behavior.

## E. Tile interaction and appearance

- E1 short left click executes one placement.
- E2 left drag past the WPF drag threshold reorders and executes zero placement.
- E3 a drag finishing over the source tile is a no-op, not a placement.
- E4 persisted target tile order still uses existing `IntentEntry` order.
- E5 generic order still uses existing `LibraryEntryIds` order.
- E6 right click opens tile edit affordances without executing placement.
- E7 targeted alias/color/shape persist and never alter Template identity or placement semantics.
- E8 generic appearance metadata, if added, is per-palette/per-entry and does not rename the live YMM4 Template.
- E9 old settings missing shape/appearance metadata load with deterministic defaults.
- E10 Rounded / Square / Circle remain finite presets; high-contrast/readability behavior remains usable.
- E11 direct settings-mutating tile edits do not overwrite an unrelated staged Settings draft.
- E12 360px/narrow layout remains reachable/readable after context menu/shape changes.

## F. Expression specialist

- F1 one normal row click navigates CurrentFrame to the Voice and selects it through the supported public route.
- F2 row navigation itself mutates no Timeline items and writes no settings.
- F3 ComboBox still receives the click normally; row navigation does not swallow/drop-down interaction.
- F4 expression choice applies immediately.
- F5 second choice atomically replaces the exact associated Plugin-managed bundle.
- F6 `配置しない` removes only that exact associated bundle.
- F7 manual/unassociated items remain untouched.
- F8 reopen/refresh reconstructs from exact association identity.
- F9 normal immediate mode does not show an always-required `表情を配置` button.
- F10 batch Place remains reachable when an imported/batch assignment is actually pending.
- F11 Resync remains reachable as maintenance but is not a primary always-visible normal action.
- F12 no private/reflection/UI-Automation preview refresh hack is introduced.
- F13 acceptance claims CurrentFrame/selection navigation only; it does not falsely claim forced pixel preview redraw.

## G. Dirty-draft / system-state safety

- G1 dirty edits to an unrelated Set do not block expression immediate apply.
- G2 dirty edits to an unrelated Set do not block `配置しない`.
- G3 dirty edits to the exact Set/source used by the requested expression operation block it before mutation.
- G4 relevant-dirty error text identifies the affected Set rather than saying only "some settings are dirty".
- G5 association serial allocation for immediate trial does not require writing unrelated user Settings.
- G6 existing Timeline tags are observed so a restarted session does not collide with IDs already present in the scene.
- G7 settings-mutating reorder/appearance operations do not silently merge over a staged draft.
- G8 failure in any admission/preflight path leaves Timeline and saved settings unchanged.

## Human acceptance remains separate

A native PASS is not final hands-on acceptance. The next candidate must again be tried in the user's real editing environment, including representative templates/PSD content and actual editing rhythm.
