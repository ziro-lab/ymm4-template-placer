## R2-B — unified placement surface adapter

Primary files:

- `IntentWorkspaceViewModel.cs`
- `IntentPalettePanel.xaml[.cs]`
- `PaletteViewModel.cs` / QuickDrop-facing APIs as delegated backend only
- new small adapter records/classes if useful

Implement one visible Set/tile surface:

- Selection context -> matching targeted `IntentPalette` Sets;
- Generic context -> Style `PaletteDefinition` Sets;
- no common-path Intent tabs;
- 1 Set hides the Set selector;
- small Set counts use segments/buttons; larger counts use picker;
- current context title remains visible;
- switching context restores the last Set for that context where safe;
- execution delegates to the existing `IntentExecutionPlan` or `QuickDropPlanner`.

Do not copy planner logic into the adapter.
