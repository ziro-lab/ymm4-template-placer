## Data-model sizing decisions

### Tile shape

No new Set shape field.

Bulk action writes existing:

- targeted `IntentEntry.Shape`
- Generic `PaletteTileAppearance.Shape`

### Tile color

No model expansion. Reuse existing finite `IntentTileColor`.

### Layout and shortcuts

Prefer one small global presentation envelope in `PlacerSettings`:

```text
PaletteLayoutMode = Auto | Fixed
FixedColumnCount
PositionShortcuts[]
```

Position shortcut entry means:

```text
slot index + explicit key gesture
```

It must not contain LibraryEntryId / Palette entry ID.

Old settings with no presentation envelope load as Auto + no shortcuts.

### Generic collision direction

Add one optional/compatibility-safe search mode so old LayerPolicy JSON retains old behavior.

Do not reinterpret an absent field as a new one-direction policy.

### Expression viewport follow

Persist one small enum:

```text
Off | WhenOutside | Always
```

Default for missing old settings: `WhenOutside`.

## Host adapter boundary

Do not leak WPF host discovery through the product.

Use a small adapter whose responsibilities are only:

- resolve known Preview seek capability;
- resolve known Timeline viewport contain/scroll capability;
- return unavailable when the exact capability cannot be proven.

The root ViewModel decides behavior/fallback.

No version-number gate.

## Async navigation ownership

Do not convert random ViewModel paths to fire-and-forget.

The expression navigation path is the only Round 3 operation requiring async host work.

Use one explicit root-owned latest-wins coordinator/state. The View may await/forward the user event, but it must not decide seek ordering, degraded mode or viewport behavior.

## Native proof additions

At minimum product proof must recreate these host/product facts:

1. Timeline-only row navigation can leave playback start stale in the isolated host fixture.
2. product row navigation with the Preview seek adapter starts playback near target.
3. WhenOutside uses public contain + scroll semantics.
4. missing-capability fakes fail closed and leave independent navigation features working.
5. position shortcuts use the same placement command/preflight path as mouse.
6. auto Voice refresh does not react to association Remark-only mutation.
7. old settings missing all Round 3 fields preserve deterministic defaults.

## Documentation rule

Do not update `docs/USAGE.md` during prep or partial implementation.

Update it only after the Round 3 source/native candidate is green so user documentation describes the actual built UI.

## Stop conditions

Stop and review before proceeding if implementation appears to require:

- coordinate-derived Timeline layer;
- OS-global keyboard hook;
- new placement engine;
- arbitrary reflection scan for Preview internals;
- private playback fields;
- fake input/UI Automation for Preview;
- destructive migration of legacy settings;
- shortcut ownership on individual templates.
