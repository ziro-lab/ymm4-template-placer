# v0.4 integrated acceptance

This document defines the final verification gate. It is not itself a PASS certificate. A delivered artifact must contain the matching `provenance.json`, `v04-acceptance.json`, `proof-log.txt`, build logs, release smoke marker and `package-checks.json`. Stage checkpoint documents identify concrete audited runs.

## Required evidence

The pinned host is real Windows YMM4 4.55.1.1 Lite, ZIP SHA256 `125860147cc33b831fc1a6d6ea996958001c2ead3b0d37f7d900251d5617db9b`.

`NativeAcceptanceProof.cs` checks the actual assembly version 0.4.0.0 and every required completed stage before writing the 18-item manifest and `W12=PASS` / `V04=PASS`. `RunNative.ps1` requires both the regression result and integrated v0.4 evidence. `PackageVerified.ps1` independently checks all stage markers, manifest IDs/results, build warning/error counts, release DLL identity/version, archive members and archived DLL hash before generating a package.

W1 is the frozen regression baseline; W2 is covered by the add-only plan/atomicity/native Undo checks within the P paths. There are no invented W1/W2 log markers. The required log markers are P1-P9, W3-W11, W12_UI, W12 and V04.

## Additional Profile coverage

Character Expression is proved in W7/W8. `NativeSelectionProof.cs` proves W9 Target Companion and Point Emphasis: real WPF Save/Preview/Place, singleton non-Face clone, five anchors, floor rounding, offsets, full-span Layers, preserved source and native Undo/Redo.

`NativeRangeProof.cs` proves W10: unordered multi-selection, mixed Characters with a neutral Template, the maximum end of an earlier-starting long Item, padding, exactly one overlay, late blockers, settings migration and Undo/Redo.

`NativeBoundaryProof.cs` proves W11: exactly the selected pair, same-start ambiguity, exact cut / small gap / small overlap, both tolerance boundaries, explicit earlier-exclusive-end anchor, no substitution of a nearby unselected cut, native Undo/Redo and preserved unrelated Items.

All Profiles use the existing LayerPlanner / PlacementPlan. No new Timeline mutation engine is used for a Profile.

## W12 UI and packaging

`NativeFinalUiProof.cs` checks real hosted controls and binding status, manual Style switching, numeric save normalization, distinct copied Preset names, search and empty-result guidance, all four tab surfaces and normal/narrow screenshots. UI review must inspect the screenshots in addition to the state assertions; measurable dimensions alone do not establish absence of clipping.

`PackageVerified.ps1` permits exactly these root payload files: the plugin DLL/deps.json, two Open XML DLLs, README, third-party notices, provenance and acceptance manifest. It verifies the DLL extracted from the `.ymme` has the same SHA256 as the native-smoked distribution DLL. Source ZIP is generated by `git archive HEAD`, and required source/test/docs entries are checked.

## What this does not establish

- Native synthetic fixtures do not prove the rendering of every user PSD asset or third-party plugin combination.
- WPF AutomationPeer command invocation is not a claim of physical mouse/keyboard injection coverage.
- The release DLL load and archive identity checks are not an end-to-end physical `.ymme` installer test.
- A normal/narrow screenshot is not every DPI, accessibility setting or host theme.
- Compiler Warning 0 / Error 0 is distinct from GitHub Action runtime deprecation notices.
- Compatibility is pinned to the tested host, not an untested future YMM4 version.

Association/Resync is the explicit Voice Expression path only. Quick Drop and selection Profiles create independent Items. Continuous sync, fuzzy recovery and copy/paste ID repair remain out of scope.
