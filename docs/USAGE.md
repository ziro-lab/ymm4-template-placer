# YMM4 Template Placer v0.4.0

よく使うYMM4テンプレートをパレットにまとめ、選んで置くプラグインです。最初はプロジェクトのコピーで試してください。

## インストール

検証対象はWindows / YMM4 4.55.1.1 Lite / .NET 10です。`.ymme`をYMM4の通常のプラグイン導入手順でインストールし、YMM4を再起動してください。

手動導入では、YMM4を終了して次の4ファイルを `YMM4/user/plugin/Ymm4TemplatePlacer/` へコピーします。旧DLLを別のプラグインフォルダへ重複して残さないでください。

```text
Ymm4TemplatePlacer.dll
Ymm4TemplatePlacer.deps.json
DocumentFormat.OpenXml.dll
DocumentFormat.OpenXml.Framework.dll
```

DLL本体だけではExcel機能の依存部品が不足します。Excel本体やCOM自動操作は不要です。Microsoft.Windows.SDK.NET.dll / WinRT.Runtime.dllはYMM4側を使用し、同梱しません。YMM4本体、キャラクター素材、検証fixtureも通常DLLには含みません。README、THIRD_PARTY_NOTICES、provenance、v04-acceptance、ux-acceptanceは説明・検証情報です。

## まずテンプレートを追加して置く

YMM4で対象シーンを開き、ツールメニューから **YMM4 Template Placer** を開きます。最初にパレットが表示されます。

```text
パレット → ＋ テンプレートを追加 → 元のYMM4テンプレートを選択
→ 必要なら短い表示名を入力 → パレットへ追加
→ 項目をダブルクリック、または選択して［再生位置へ配置］
```

初回は最初の追加と同時にパレットを作ります。以後は上の一覧で追加先を選びます。元のテンプレートは、アイテムを1つだけ含むものが対象です。元データがまだない場合はYMM4で登録し、この画面の［一覧更新］を押してください。

同じ元データに対する登録が1つあれば再利用します。同じ登録を複数のパレットに入れられます。元データの名前や内容は変更せず、プラグインには参照だけを保存します。再利用時の表示名は共有なので読み取り専用です。変更する場合は［テンプレート管理…］で行います。

元データや登録が複数あって一意に決まらない場合は停止します。似た名前を選んだり、壊れた参照を自動修復したりしません。追加中に管理画面へ移っても［戻る］で入力中の名前・選択・追加先を保ったまま戻れます。タイムラインの選択を変えても、開いている追加画面の追加先は勝手に変わりません。

## パレットを整理する

［＋ パレット］では **パレット名** と **連動キャラクター（指定なしでも可）** を設定します。キャラクター／スタイルという内部モードを選ぶ必要はありません。名前変更・項目を外す・パレット削除は［このパレットを編集］にあります。これらで元テンプレートや配置済みアイテムは削除しません。

連動キャラクターを指定したパレットを使っている間は、音声・表情をタイムラインで単体選択すると、そのキャラクターのパレットへ一時切り替わります。選択解除や複数選択では、直前の手動選択へ戻ります。パレットを明示的に選び直した操作は、古い選択状況で即座に取り消されません。次のタイムライン選択から連動が再開します。

連動キャラクターなしのパレットは、字幕・戦闘演出などの手動パレットです。使用中にキャラクターの音声を選んでも、勝手に別パレットへ移りません。同名キャラクターを一意に判別できない場合も、自動で選びません。

### 再生位置へ配置

ダブルクリック／［再生位置へ配置］は **現在の再生位置** と **元テンプレートの長さ** を使います。選択した音声の開始や長さに合わせる操作ではありません。関連付けを作らないため再同期の対象外です。コピー元のプラグイン関連タグは、追加する独立コピーからだけ外します。

連動パレットでは、基準／前面／背面を選べます。基準は保存したレイヤー条件、前面は同区間の同キャラクター関連アイテムより大きい番号、背面は小さい番号へ探索します。同キャラクターの重なるアイテムがない場合は基準へ戻ります。無関係なキャラクターは前後の基準を変えませんが、どのアイテムも衝突判定の対象です。

開始だけでなく予定の全長を確認します。空きがなくても既存アイテムを移動・短縮せず、前面・背面の探索は反対方向へ回り込みません。レイヤー設定の編集後は保存してください。未保存のまま配置しません。探索上限9999はプラグインの安全上限で、YMM4自体の上限を意味しません。

## セリフを見ながら表情を選ぶ

［表情一覧］は **No／キャラ／セリフ／テンプレート** が中心です。各行で表情を選び、［表情を配置］を押します。初期の配置範囲は **音声と同じ** なので、プリセットを作る準備は不要です。未選択の行は何もしません。

候補は同じキャラクターの表情アイテム（TachieFaceItem）を1つだけ含むテンプレートです。パレットにある候補は短い名前で先頭に表示します。狭い画面では選択行のセリフが下に全文表示され、長い部分はその枠内をスクロールできます。開始・長さは行のツールチップで確認できます。

候補なしの行には［＋ 表情を追加］が表示されます。その行のキャラクター向けの追加画面へ直接進めます。元の表情テンプレートが存在しなければ、YMM4で登録して［一覧更新］してください。追加後は同じ一覧へ戻り、ほかの行で選んだ内容も保持します。追加した表情を自動で全行へ割り当てることはしません。

### 配置範囲を変える

［配置範囲: 音声と同じ］を開くと、長さ・開始終了の調整・レイヤー条件を編集できます。保存、複製、削除、編集を戻す機能は残っています。複数の条件を保存した場合は切替欄が表示されます。未保存の編集があれば配置・再同期を停止します。

「次の同キャラの音声まで」では、現在音声の終了から次の同キャラクター音声の開始までが最大間隔以内なら、その開始まで伸ばします。次の音声が重なっていても、それだけを理由に現在の音声より短くしません。明示的な開始・終了調整は基準区間へ加算されます。単位はフレームです。

必要な配置を1行でも安全に計画できなければ、全体を追加前に停止します。既に関連表情のある音声へ勝手に置換・重複追加しません。現在の関連表情を合わせ直すには再同期、消すにはYMM4標準の削除を使ってください。

［更新］は音声一覧を読み直す操作で、割り当てを保持する操作ではありません。選択済みの場合は確認します。シーン変更後や古いExcelデータを使っている場合は、更新・再出力してください。

## 選択したアイテムに飾りを置く

**YMM4のタイムライン**で基準にするアイテムを選び、［選択配置］で「何を置く？」「どこに置く？」を決めて［配置する］を押します。表情一覧の行選択とは別です。同じ表示名がある場合は、下のキャラクター・元テンプレート名で区別できます。

| 表示される配置方法 | 選択数 | 置き方 |
| --- | --- | --- |
| 対象全体に合わせる | 1 | 対象の開始～終了に調整値を加えた範囲 |
| 一点を強調 | 1 | 開始／25%／50%／75%／終了の基準点に調整値を加え、固定長で配置 |
| 選択範囲を覆う | 2以上 | 全選択の最小開始～最大終了に前後の余白を付ける |
| 2つの境界に置く | 2 | 先に始まるアイテムの終了を基準に固定長で配置 |

使えない選択数の方法は表示しません。選択数を変えて、記憶している方法が使えなくなった場合は、表示された方法を明示的に選んでください。保存済みの条件を勝手に別のものへ置き換えることはありません。

条件は必要なときだけ編集・保存します。入力が揃うと配置予定が自動で表示されるので、毎回［予定を更新］を押す必要はありません。自動更新はこの画面を開いている間の選択・テンプレート・保存条件の変更時だけで、常時監視やポーリングはしません。元アイテムを動かすなど、選択を変えない編集のあとに表示を更新するには［予定を更新］を使います。**実際の配置時は、表示済みの計画を流用せず最新状態で必ず再計算・検証します。**

割合の端数は切り捨てです。終了は末尾の次フレームで、開始100・長さ40なら140です。範囲は選択順に関係なく全体を覆う1つのアイテムを追加し、前後の余白は0以上です。

境界は `abs(先の終了 − 後の開始) <= 許容差` の場合だけ使います。同じ開始位置なら前後を推測せず停止します。許容した隙間・重なりの中間点へずらしたり、近くの別カットを探したりしません。初期条件は許容差0、開始調整−15、長さ30です。

キャラクター付きテンプレートと対象のキャラクターが違う場合は停止します。複数キャラクターを覆う共通の飾りには、キャラクターなしのテンプレートを使用してください。

## 表情を再同期する

表情一覧から配置した音声と表情には、ユーザーの備考本文を残して弱い関連目印を付けます。

```text
音声: CWT_TPL:V=<連番>
表情: CWT_TPL:S=<連番>;P=expression
```

音声を動かした後、タイムラインで関連する音声または表情を選び、**表情一覧にある［選択した表情を再同期］**を押します。表情を選んだ場合はその表情だけ、音声を選んだ場合はその音声を参照する関連表情が対象です。関連なし・未選択では無効になり、マウスを置くと必要な操作を確認できます。

再同期は **現在保存している表情の配置範囲** を使い、過去の条件は保存しません。連番と実際のキャラクターが一致し、対象音声が1つに決まる場合だけ更新します。対象なし・ID重複・不正タグ・衝突などは推測せずスキップし、件数と理由を残します。更新できた分はYMM4の「元に戻す」1回で戻せます。

常時追従、音声削除への自動対応、コピーしたIDの修復、シーン全体一括同期はありません。再生位置への配置と選択配置は独立したアイテムで、再同期の対象外です。

## Excelでまとめて割り当てる

表情一覧の［Excelでまとめて編集］を開きます。

```text
Excelへ出力 → AssignmentsのTemplate列を選択・保存
→ Excelから読み込み → 表情一覧を確認 → 表情を配置
```

読み込みだけではタイムラインを変更しません。配置には出力時ではなく現在保存している表情の配置範囲を使います。Excelは表情の割り当て専用です。Template列以外のNo、Character、Frame、Length、Serifや非表示シートを編集しないでください。空欄は配置しない意味です。

音声や元テンプレートを変更した場合は再出力してください。CatalogのT番号はそのブック内だけで有効です。同キャラクターの同名テンプレートは区別してから使います。音声・テンプレート各50,000件、読み込み16 MiBは安全上限であり性能保証ではありません。通常の.xlsxのみ対応し、数式評価やマクロ実行はしません。UI内の複数行一括割り当ては今回追加していません。

## 管理とエラーからの復旧

普段の登録に［テンプレート管理…］を開く必要はありません。元参照の確認、表示名の共有変更、再リンク、登録解除のための画面です。キャラクターは元アイテムから読めれば自動表示します。必要な手動指定やキャラクターなしへの変更は［キャラクター指定を変更］にあります。

元データの削除・名前変更などで参照が切れたら、管理画面で対象登録と正しい元テンプレートを選び［再リンク］します。複数候補は自動で選ばず、登録解除も明示操作だけです。

未保存なら保存・編集を戻す、空きレイヤーなしなら配置条件を見直す、古い一覧・Excelなら更新・再出力、という順で修正できます。不正入力や参照切れで失敗しても、入力を不要に消しません。成功メッセージは画面を移ると消えます。エラーと再同期のスキップ結果は残し、長いメッセージはその枠内をスクロールできます。

設定は `%LOCALAPPDATA%/Ymm4TemplatePlacer/settings-v04.json` です。壊れた設定や別ツールからの変更を勝手に上書きしません。設定エラー時は元ファイルを退避・確認し、ツールを開き直してください。既存設定の内部形式、厳密な参照、保存済みプリセットの意味は維持しています。

## 検証情報と境界

配布には `provenance.json`、既存18項目の `v04-acceptance.json`、今回の必須UX12項目の `ux-acceptance.json` を同梱します。Evidenceには段階別assertion、buildログ、release DLLロード記録、通常幅・360px幅の画像、計算コスト、SHA256があります。必要な全段階を通らなければpackageを生成しません。

実YMM4 4.55.1.1内で人工fixtureと実際のWPFコントロール・コマンドを検査しています。初心者本人による操作実験、物理マウス・インストーラ操作、任意のPSD素材、全DPI・テーマ、将来YMM4まで確認したという意味ではありません。通常配布DLLの実ホストロードと、.ymme内DLLの一致は別途検査しています。
