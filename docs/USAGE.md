# YMM4 Template Placer v0.4.2

UI Micro Polish Hands-on Candidate の使い方です。主画面は **「配置」「表情をまとめて」「設定」** の3つです。今回のCandidateでは高頻度のUI操作を短縮しています。実験的なTachie Preset方式はまだ含まれていません。

自動検証の基準は **YMM4 4.55.1.1 Lite / Windows / .NET 10**。実際のPSD素材や普段のプロジェクトでの受入れ確認は別なので、最初は別名保存したコピーで試してください。

## インストール・更新

YMM4に `Ymm4TemplatePlacer-v0.4.2.ymme` をインストールし、再起動します。Toolメニューの「ユーティリティ」グループから「YMM4 Template Placer」を開きます。YMM4の表示言語によってグループ名は変わります。

インストール先の固定フォルダは `YMM4/user/plugin/Ymm4TemplatePlacer/` です。版が変わっても `.ymme` 内部のフォルダ名は変わりません。以前のCandidateで `Ymm4TemplatePlacer-v0.x.y/` のような版付きフォルダが残っている場合は、YMM4を閉じ、バックアップを取ってから旧Template Placerの該当フォルダだけを整理してください。他のプラグインや素材は削除しないでください。

設定ファイルは `%LOCALAPPDATA%/Ymm4TemplatePlacer/settings-v04.json` です。設定・プロジェクト・使用素材は別々にバックアップしてください。

## まず1つ配置する

YMM4のテンプレート機能へ、繰り返し使いたいアイテムを登録します。Template Placerはその元を参照し、配置時に独立したコピーを作ります。元テンプレートを改名したり、内容をプラグイン設定へ複製したりはしません。

「配置」では、タイムラインで最後に行った操作に応じて使えるセットが切り替わります。

| タイムラインの操作 | 配置するもの・位置 |
| --- | --- |
| アイテムをクリック・選択 | その種類・選択数・キャラクター条件に合うセット。対象の開始・終了など、保存した関係に従います。 |
| 背景または時間の目盛りをクリック | 汎用セット。現在の再生位置に、テンプレートの長さで配置します。 |

背景や目盛りをクリックして汎用へ切り替わっても、YMM4側の選択は無理に解除しません。再生やキーボードによる時間移動だけでは、セットの文脈を勝手に切り替えません。

セットが1つなら、そのままタイルを押します。少数なら並んだセット名で切り替え、多い場合は一覧から選びます。「やりたいこと」を別に選ぶ階層はありません。

タイルは **左クリックで配置、左ドラッグで並べ替え、右クリックで編集** です。ドラッグは配置と別操作で、離しただけで配置されることはありません。通常のタイル配置は追加操作です。同じタイルを再度押すと、もう1回の追加になります。配置全体はYMM4の「元に戻す」1回で戻せます。

## タイルの表示・形・並び順

右クリックの「表示名を変更…」「色」「形」で、そのセット内のタイルを編集します。表示名を空欄にすると元名の短い部分を使い、同じ表示名がある場合だけ区別を補います。元のYMM4テンプレート名や参照先は変えません。

色は標準・ピンク・黄・緑・青・紫の有限候補です。色は細い横棒ではなくタイル本体と枠へ反映し、文字はシステムの文字色を使います。High Contrastではシステム色を優先します。任意のRGBやカラーピッカーはありません。

形は **角丸・四角・丸** です。現在のセット全体の形をそろえる操作は、配置画面右下の **「⚙ 簡易設定」** にあります。一括変更後も、1枚だけ右クリックで別の形へ変えられます。新しいタイルが永続的に形を継承する設定ではなく、その時点の各タイルを変更する操作です。

配置画面での並べ替え・表示編集・一括形状変更は、安全に検証できた変更から自動反映します。入力途中や外部変更との競合がある場合は上書きせず止めます。設定画面の「↑ 上へ」「↓ 下へ」でも並べ替えられます。

## 配置パネルの簡易設定・固定列・位置ショートカット

配置画面右下の **「⚙ 簡易設定」** は、設定タブへ移動するボタンではありません。現在の配置パネルでよく触る見た目・操作だけを、その場で変更する小さいパネルです。

ここでは、

- 現在のSetの全タイル形状（角丸・四角・丸）
- 自動（Auto）/ 列数を固定
- 固定列数
- 位置ショートカットのON/OFF
- 位置ショートカットの割り当て

を変更できます。Setの作成・削除、対象条件、配置関係、レイヤー探索範囲、テンプレート追加などの**構造設定は従来どおり「設定」タブ**で行います。

Auto/Fixed、固定列数、位置ショートカットはセットを切り替えても共通です。

- **自動（Auto）**：初期値。ウィンドウ幅に合わせて折り返します。
- **列数を固定**：1～16列で指定します。広い時は固定した列数のままタイルが正方形で均等に伸び、幅を使い切ります。狭い時は104pxを下回らず、必要な場合は横スクロールになります。

位置ショートカットは初期状態ではOFFで、キーの割り当ても空です。固定列にしたうえで「位置ショートカットを使う」を有効にし、「＋ キーを設定」で位置とキーを入力します。有効な設定は自動反映されます。入力例は `A`、`Ctrl+1`、`Shift+F1` です。

画面では位置を **1始まり** で数えます。4列なら位置1が1段目左端、位置4が1段目右端、位置5が2段目左端です。内部の `slot 0` は画面の位置1、`slot 4` は位置5に対応します。

キーはテンプレート名ではなく **表示位置** に付きます。並べ替えたり別のセットへ切り替えたりすると、その位置に現在あるタイルが実行されます。タイルごと・セットごとにキーを持たせる設定ではありません。

使えるのは、Toolが表示されていて「配置」タブが開かれ、固定列・ショートカット有効の条件を満たすときです。YMM4メインウィンドウにフォーカスがあれば、Template Placer自身へフォーカスを移す必要はありません。文字入力欄、ComboBox、DataGrid編集中、メニュー、モーダルダイアログではキーを奪いません。Toolを隠した時、「設定」や「表情をまとめて」を開いた時、Auto時には配置ショートカットを実行しません。OS全体へ効くホットキーではありません。

キーの長押しで連続配置はしません。割り当てがない位置・存在しない位置・使えないタイルは実行しません。YMM4で普段使うキーと重ならない割り当てにしてください。有効な位置キーでの実行も、マウスと同じ配置前検査・配置・Undoを使います。

## 汎用配置のレイヤーをすばやく指定する

汎用セットを表示すると、上部の **「汎用・時間位置」** の右側に、レイヤー番号と「塞がった時の動作」が**常時表示**されます。設定ポップアップを開く必要はありません。

レイヤー番号欄では、

- 数字をクリックして直接入力
- **マウスホイールで±1**
- Enterで適用
- Escで未確定の入力を戻す

が使えます。ホイールは番号欄の上だけでレイヤー変更として扱い、それ以外では通常のスクロールを奪いません。保存済みの探索範囲を超えて増減しません。

適用前の変更がある間は、古い番号で配置しないようタイル実行を止めます。

| 指定レイヤーが塞がっていたら | 動作 |
| --- | --- |
| 配置しない | 何も置かずに停止します。 |
| 上の空きを探す | 小さいレイヤー番号の方向だけ探します。 |
| 下の空きを探す | 大きいレイヤー番号の方向だけ探します。 |

**指定レイヤーが空いていれば、どの動作でも必ずそこへ置きます。** 空きの判定は開始位置だけでなく、配置する時間の全体を対象にします。探索するのはセットに保存した範囲内だけで、反対方向へ回り込まず、既存アイテムを移動・短縮・削除して場所を作ることもありません。

探索範囲は「設定」→「汎用」→該当セット→「細かく調整」で変更します。プラグインの探索上限は9999で、指定番号は保存済みの範囲内に収めます。

旧設定の「テンプレートのレイヤー」や旧範囲探索は、読み込んだだけでは新しい動作へ変更しません。旧動作のままの場合はその旨を表示します。数値を入力して適用すると、新しい数値指定へ明示的に切り替わります。

タイムラインをクリックした高さからレイヤー番号を推測する機能はありません。また、汎用配置で使えるのは現在 **1アイテム入りのテンプレート** です。複数アイテム入りは、対象アイテム用のセットを使ってください。

## セットを作る・配置関係を決める

「設定」上部で「汎用」または使うアイテムの種類を選び、セット欄の「＋」で作成します。現在利用できる種類を直接表示し、「その他」の中には隠しません。タイムライン上の選択を元に作成すると、その種類・選択数・キャラクターを初期条件に使えます。

対象アイテム用セットでは「このセットの動き」の説明を見ながら「どう置く？」を設定します。選択アイテムの開始・終了・中央、選択範囲、2件の境界、前後のアイテムなどが基準です。周囲の参照先がない場合の動作も設定します。条件上の「配置しない」は、何も追加しない結果です。曖昧な参照先を勝手に選びません。

必要な欄だけ表示し、開始・終了差分、固定長、最大間隔、境界許容差、レイヤー範囲などは「細かく調整」にまとめています。数値の時間指定はフレーム単位です。複数種類・複数選択の条件は「対象の詳細・複数種類」で明示的に設定します。

セット名は自由に付けられ、同じキャラクター用に複数作れます。「セットの管理」で複製・順序変更・削除ができます。設定画面では、完全な設定として検証できた変更を自動で反映します。数値などが入力途中で不正な間は保存せず、その入力を画面に残して「反映待ち」と表示します。別のToolや外部編集と競合した場合も勝手に上書きしません。

設定を開いてから行った変更をまとめて取り消したい場合は **「今回の変更を戻す」** を使います。自動反映を何回行った後でも、その設定セッションを開いた時点へ戻します。タイムラインや元のYMM4テンプレートは変更しません。

## テンプレートをセットへ追加する

追加先を選んで「テンプレートをまとめて追加」を開き、必要な元にチェックを付け、「チェックしたテンプレートを追加」を押します。検索で隠れたチェック済み項目も保持します。元がない・曖昧・キャラクター条件が違うなどの問題があれば一括追加全体を止め、選択を残します。追加後、設定全体が有効なら自動反映します。

初回は、表情を含む元テンプレートからキャラクター別の表情セットを作ります。曖昧な元や複数キャラクターの混在は自動登録しません。初回取り込みはメモリー上で行い、ロードだけで設定ファイルを書き換えません。設定画面で有効な変更が行われた時に保護された保存経路で反映します。

後からYMM4へ増やした表情を取り込む場合は「新しい表情を取り込む」を使います。ずっと自動追加し続ける機能ではなく、一度取り込んでセットから外した候補も勝手に復活させません。必要な元は手動のチェック追加でも登録できます。

対象アイテム用セットでは複数アイテム入りテンプレートも使えます。内部の時間差・レイヤー差・長さ・内容を保ち、衝突回避でも全メンバーを同じ差だけ動かします。全件置けなければ1件も置きません。新しいYMM4グループを自動生成する機能ではありません。

## 表情をまとめて：行クリックと即時反映

「表情をまとめて」には、現在のシーンのボイスが並びます。Voiceの追加・削除、キャラクター名、開始、長さ、レイヤー、セリフが変わると自動更新します。このタブへ戻る時にも確認します。表情の関連付けで備考だけが変わった場合は、行を作り直しません。通常の「シーン更新」ボタンはありません。

**行を1クリック** すると、そのボイスの開始へ移動し、YMM4の選択とPreviewの再生位置を同期します。高速に別の行をクリックした場合も、最後に選んだボイスを最終位置にします。表情のComboBoxを開いた時も同じVoice移動経路を使うので、候補を選ぶ前にそのセリフとPreviewを確認できます。ComboBox自体の操作は奪わず、そのまま候補を選べます。

タイムラインの表示範囲の追従は「設定」→「全体の表示・操作」で選べます。

ボイス一覧の共通行高は32～96pxです。**どのボイス行でも、行の下端にマウスを合わせて上下ドラッグ**すると、一覧全体の行高が同時に変わります。ドラッグ中は見た目だけを即時プレビューし、離した時に最終値を1回だけ保存します。

上部の「行の高さ」欄には現在値が表示され、数値を直接入力してEnterでも変更できます。Escで元の値へ戻します。全行共通の高さで、行ごとに別の高さを持つ仕組みではありません。行高を大きくしても文字サイズは縮めず、長いセリフを複数行で確認できます。

| 設定 | 表示範囲の動作 |
| --- | --- |
| 追従しない | 表示範囲を動かしません。再生位置の同期とは別です。 |
| 画面外の時だけ追従 | 初期値。選んだボイスの開始が表示外の場合だけ動かします。 |
| 常に追従 | 行を選ぶたびに、その開始へ表示範囲を動かします。 |

テンプレートの選択変更は **即時反映** です。別の候補を選ぶと、そのボイスに関連付いたTemplate Placer生成物のまとまり全体を置き換えます。「配置しない」は、そのボイスの正しく識別できた関連生成物だけを外します。手動配置や無関係なアイテムは変更しません。配置前検査が失敗すれば、前の表情と選択を保持します。

同じ行で続けて表情を試す間は、短い試用操作を1回のUndoへまとめます。別の行・作業への移動、外部編集、Toolのライフサイクルなどで区切り、無関係な編集を巻き込みません。

候補は、表情候補として有効にしたセットからキャラクター名で絞ります。同じ元が複数セットにある場合はセット順・タイル順で先に出る候補を使います。異なる配置方法を使い分ける場合は「配置」からセットを選んでください。候補なしは「＋ 表情を追加」から設定へ進めます。

反映待ちの入力途中設定があっても、無関係なセットの内容なら即時反映を妨げません。実行する表情のセット・元に関わる設定が未確定の場合は、正しい値へ直して自動反映されるまで止めます。

## Excelと未配置作業の保護

通常の即時反映では「表情を配置」ボタンは出ません。「Excelでまとめて編集」から書き出した `Assignments` シートのテンプレート列を編集し、読み込んだ未配置の割り当てがある場合にだけ、まとめて確定するボタンを表示します。

Excelの読み込みだけではタイムラインは変わりません。「表情を配置」時に、現在保存してあるセットの条件で検証して反映します。No・キャラクター・開始・長さ・セリフ、行数、非表示シートは変更しないでください。空欄の行は配置しない指定で、既存生成物の削除指示ではありません。

未配置の割り当てがある状態でVoiceやシーンが変わっても、自動更新でその作業を黙って捨てません。割り当てを保持したまま変更を知らせ、古い情報のまま配置・出力しないよう止めます。同じYMM4セッション中のTool再生成でも、この未配置情報を保持します。YMM4終了・クラッシュ後まで復元する保証ではありません。

復旧は、現在のVoiceと一致するExcelを読み込むか、未配置内容を確認して **「メンテナンス」→「一覧を読み直す」** を選びます。後者は未配置の割り当てを破棄する確認を出します。元のExcelは残しておいてください。Voiceや元テンプレートが変わって出力時と一致しなくなったブックは、再出力して編集し直します。自動差分マージはしません。

## 関連表情の再同期・旧設定

表情一覧から反映した生成物は、備考の弱い目印で元ボイスと関連付けます。通常のタイル配置はこの関連付けを作りません。元テンプレートとユーザーの備考本文は保持します。

関連ボイス、または関連生成物のメンバーを選び、「表情をまとめて」→「メンテナンス」→「選択した表情を再同期」で、まとまり全体へ保存済みの配置関係を再適用します。Voice移動に伴う一覧更新と、生成物を動かす再同期は別です。生成物は自動で追いかけません。

メンバーの欠落・コピー、参照の変更、重複した対象などで正しく識別できない場合、そのまとまりはスキップします。部分再構築や近さによる推測はしません。一部だけ成功した場合はスキップ理由を知らせ、成功した更新群をUndo1回で戻せます。

旧Library・Palette・Preset・Intent・Quick Dropのデータと互換処理は保持していますが、通常UIには旧workspaceへの入口や戻り操作を出しません。古い設定に旧workspaceのフラグが残っていても、通常起動は現在の画面になります。旧データを勝手に相対ルールへ移行したり削除したりはしません。

元テンプレートを改名・移動・削除して参照が切れた場合は、自動で別の元へ置き換えません。YMM4側の元を確認し、現在のセットで不要な参照を外す・正しい元を追加するなど、意図を確認して修正してください。同名の実キャラクターが複数登録されている場合も、曖昧なまま配置せず止めます。

## 検証範囲と確認用資料

YMM4のバージョン番号だけで一律に止めず、既知のpublic/WPF機能が存在するものを使います。ただし未検証の将来版まで完全互換を保証するものではありません。

Previewのpublic seekが利用できない場合でも、CurrentFrame・選択・利用できるviewport追従は続けます。viewport側が利用できなくても、Preview同期は独立して行います。使えなかった機能だけを短く知らせます。代わりに偽クリック、座標からのレイヤー推測、privateな再生状態の操作はしません。

Release検証では、配布物の `provenance.json` にsource HEAD・実行run・DLLハッシュを記録し、実DLL smokeとパッケージ構造を確認します。普段の開発ではFocused/Checkpointを使い、毎回Releaseパッケージまで作りません。これらの自動PASSと、実際のPSD素材で見た目や操作感が正しいという確認は別です。

実プロジェクトでは、PSDの表情パスとキャラクター、CharactorMotion等の効果値、複数アイテムの配置、Undo/Redo、ドラッグとクリックの境界、文字入力中のショートカット除外、行の連続クリックと再生開始を確認してください。DPI・High Contrast・他プラグイン・独自レイアウトも普段の環境で確認してください。
