# YMM4 Template Placer v0.4.1

Verified native target: **YukkuriMovieMaker4 4.55.1.1 Lite**.

このプラグインは、YMM4に登録したテンプレートを「よく使うパレット」「音声に対応する表情」「選択アイテムとの関係配置」として再利用しやすくするための補助ツールです。

配置は **add-only** です。既存アイテムを自動で削除・置換・短縮しません。配置前に予定を作り、重なりや参照切れを検証してから一括で確定します。成功した配置はYMM4のUndo/Redoで戻せます。

## 1. 最初にやること

YMM4の通常のテンプレート機能で、再利用したいアイテムをテンプレートとして登録してください。

YMM4 Template Placerを開くと、基本画面は次の3つです。

- **パレット** — よく使うテンプレートを集めて、再生位置へすぐ配置する
- **表情一覧** — 音声ごとに表情テンプレートを選び、まとめて配置する
- **選択配置** — タイムラインで選んだアイテムを基準に、別テンプレートを関係配置する

`テンプレート管理` は日常作業の主画面ではありません。参照の確認・表示名変更・再リンク・登録解除が必要なときだけ、パレットから開きます。

## 2. パレットを作る

`＋ パレット` から名前を付けます。

連動キャラクターは任意です。

- キャラクターを指定したパレットは、そのキャラクターの音声・表情を単体選択したとき自動で切り替わります。
- `指定なし` のパレットは手動で使う道具箱です。

内部ではCharacter / Styleの区別を保持していますが、通常操作でモードを理解・選択する必要はありません。

## 3. テンプレートをまとめてパレットへ追加する

パレットの `＋ テンプレートを追加` を押します。

一覧のチェックボックスから、1件でも複数件でも選べます。

- 1件だけ選んだ場合は、その場でパレット表示名を変更できます。
- 複数件では元のYMM4テンプレート名を初期表示名に使います。必要なら後でテンプレート管理から変更できます。
- 検索で選択済み項目が一時的に隠れても、選択自体は保持されます。
- 現在のパレットへ既に追加済みのものは `追加済み` と表示され、二重登録できません。
- キャラクター連動パレットでは、別キャラクターのテンプレートを最初から候補に出しません。キャラクターを持たない中立テンプレートは利用できます。

複数追加は、1件ずつ順番に保存する処理ではありません。選択した全件を先に検証し、全件が安全に解決できた場合だけまとめて保存します。

1件でも次のような問題があれば、**その一括追加全体を保存しません**。

- 元のYMM4テンプレートが削除された
- 同じ元テンプレートに複数の管理登録があり曖昧
- 追加先パレットが途中で削除された
- キャラクターが追加先と合わない
- 表情追加の元音声が変更された

入力や選択は可能な限り残すので、原因を直してやり直せます。

## 4. パレットを自分の使いやすい順へ並べる

パレット内の順番はユーザーが決められます。

各行左側の **`⋮⋮` ハンドル** をドラッグして並べ替えます。

ドラッグを使いにくい場合は、`このパレットを編集` 内の

- `↑ 上へ`
- `↓ 下へ`

でも移動できます。

並び順はそのパレットだけに保存されます。同じテンプレートを別のパレットでも使っていても、そちらの順番は変わりません。

キャラクターパレットの順番は、表情一覧でパレット由来の候補を優先表示する順番にも使われます。

行の通常ダブルクリックは従来どおりQuick Dropです。ドラッグ開始は専用ハンドルだけなので、並べ替えと配置操作を混同しません。

## 5. パレットから再生位置へ置く

パレット内のテンプレートを選び、`再生位置へ配置` を押します。

または、そのパレット項目をダブルクリックします。

配置先レイヤーは次から選べます。

- **基準** — 設定したレイヤー範囲・優先位置を使う
- **前面** — 同じキャラクターの既存表情より前面方向を探す
- **背面** — 同じキャラクターの既存表情より背面方向を探す

前面／背面は反対方向へ勝手に回り込みません。予定時間全体を見て空きレイヤーがなければ停止します。

## 6. 表情一覧

表情一覧の主な列は次の4つです。

- No
- キャラ
- セリフ
- テンプレート

開始位置や長さは主一覧を圧迫しないよう補助情報へ下げています。

テンプレート列から表情を選び、`表情を配置` を押します。未選択行は何もしません。

通常の配置範囲は `音声と同じ` として表示されます。複数の保存条件があるときだけ、条件選択UIが現れます。

### 候補がないとき

その行の `＋ 表情を追加` から、対象キャラクターの表情テンプレート追加へ直接進めます。

ここでも複数の表情テンプレートをまとめて選択できます。

追加後は候補一覧を更新しますが、**勝手にその表情を行へ割り当てません**。最終的な選択はユーザーが行います。

### 同じ表示名の表情があるとき

通常は短い表示名だけを出します。

同じパレット内で表示名が衝突した場合だけ、

`表示名 — 元Template名`

のように補助情報を付けます。内部IDやGUIDを通常UIへ出しません。

## 7. 表情の再同期

表情配置で関連付けられた音声または表情をタイムラインで選ぶと、表情一覧から `選択した表情を再同期` できます。

再同期はシーン全体へ勝手に広げません。選択中の関連アイテムだけを対象にし、IDと実際のキャラクターを厳密に確認します。

一部だけ更新できた場合は、完全成功とは表示せず、更新できなかった理由をpartial resultとして残します。

## 8. 選択配置

選択配置は内部Profile名を覚える操作ではなく、

1. **何を置く？**
2. **どこに置く？**

の順で決めます。

タイムラインの選択数に応じて、使える方法だけを表示します。

### 1アイテム

- **対象全体に合わせる** — Target Companion
- **一点を強調** — Point Emphasis

### 2アイテム

- **選択範囲を覆う** — Selection Range
- **2つの境界に置く** — Boundary

### 3アイテム以上

- **選択範囲を覆う**

使えない方法は候補に出しません。

配置予定は入力・選択変更に合わせてイベント駆動で自動更新します。常時pollingはしません。

実際の `配置する` では、表示済みPreviewをそのまま信用せず、最新のタイムライン状態から再度計画・検証します。

## 9. パレット名・候補名が同じとき

同名そのものは禁止しません。

パレット名が衝突した場合だけ、例えば

- `表情 — 小夜`
- `表情 — ミコ`

のように連動キャラクターを補助表示します。

手動パレット同士の同名も、必要なときだけ `手動 1` / `手動 2` のように区別します。

重複していない通常項目には余計な情報を追加しません。

## 10. Toolを閉じて開き直したとき

同じYMM4実行中にToolを閉じ、再度開いたことで内部ViewModelが作り直された場合でも、安全に同一と確認できる途中作業は復元します。

対象には次のようなものがあります。

- 表情一覧で途中まで選んだ表情
- 保存前の表情配置条件
- 保存前の選択配置条件
- 選択配置で選んでいたテンプレート
- パレットの未保存レイヤー設定・名前
- 新規パレット作成途中
- テンプレート追加途中の検索・複数選択
- テンプレート管理の編集中内容

復元は**同じものだと厳密に確認できる場合だけ**行います。

閉じている間に音声や参照元が変更されていた場合は推測復元せず、復元できなかった件数を表示します。

Resumeだけでタイムラインや設定ファイルを書き換えることはありません。

対象は同一YMM4プロセス内のTool close/reopenです。YMM4終了後の未保存draft復旧やクラッシュリカバリはv0.4.1の対象外です。

## 11. 削除・登録解除

復旧に手間がかかる低頻度操作だけ、実行前に影響を確認します。

### パレットを削除

確認画面に

- パレット名
- そのパレットに入っているテンプレート件数
- 元テンプレート、テンプレート管理登録、タイムラインは削除しないこと

を表示します。

### テンプレート管理から登録解除

確認画面に

- 登録名
- 何個のパレットから外れるか
- 元のYMM4テンプレートとタイムラインは削除しないこと

を表示します。

確認でキャンセルした場合、設定ファイルもタイムラインも変更しません。

パレットから単に `選択テンプレートを外す` 操作は再追加が容易なので、毎回確認は出しません。

## 12. `キャンセル` / `戻る` / `シーン更新`

作用の違う操作を同じ語にしないよう分けています。

- **キャンセル** — 今の追加・作成を確定せず破棄する
- **戻る** — テンプレート管理などの子画面から、編集中内容を保ったまま親Taskへ戻る
- **シーン更新** — 現在のシーンの音声・テンプレートを読み直す。表情一覧の現在選択はクリアされるため、必要なら確認を出す
- **一覧更新** — その場の候補一覧だけを読み直す

## 13. Excelで表情をまとめて編集

表情一覧の `Excelでまとめて編集` から出力します。

編集するのはAssignmentsシートのテンプレート列だけです。キャラクターごとの候補プルダウンが付きます。

読み込みは、

- No
- Voice snapshot
- Character
- Template候補
- 数式セル
- Schema

などを検証し、問題があれば割り当てやタイムラインを途中まで変更せず停止します。

Excelは表情割り当てを大量に行うための低リスクなbulk pathとして残しています。

v0.4.1では表情一覧そのものの複数行一括割り当ては追加していません。

## 14. エラーと状態表示

正常な状態で `利用可能` / `準備完了` のような表示を常時繰り返しません。

表示するのは主に、ユーザーが次の行動を決める必要がある状態です。

- 元テンプレートがない
- 同名・重複登録で曖昧
- キャラクターが合わない
- 未保存条件がある
- レイヤーに空きがない
- 一部だけ再同期できた
- Tool再開時に一部draftを安全に復元できなかった

成功メッセージは別Taskへ移ったら残しません。未解決エラーやpartial resultは、別の明示的な結果で置き換わるまで保持します。

## 15. Intentional boundaries

v0.4.1では次を行いません。

- 既存アイテムの自動削除・自動置換
- fuzzyなテンプレート復旧
- copy/pasteされた関連IDの推測修復
- シーン全体の常時同期
- Voice移動へのcontinuous resync
- YMM4テンプレート本体の複製DB化
- 汎用ルールエンジン
- 新しいProfile family
- 自動sort rule
- パレットのフォルダ階層
- YMM4終了後の未保存draft復旧
- 表情一覧の同キャラクター複数行一括割り当て

元のYMM4テンプレートがSource of Truthです。曖昧なときは推測せず停止します。

## 16. 検証範囲

Native検証は実際のYMM4 4.55.1.1 Lite上で、実WPF View/Commandとsynthetic native Itemを使って行います。

検証対象には、旧P1-P9 / W3-W12 / v0.4 Acceptance、Task UX WUX1-WUX7、v0.4.1 Workflow WUX8-WUX13、release DLL native smoke、Open XML、package identityを含みます。

ただし次までは保証しません。

- 任意の実PSD素材すべての描画結果
- 物理マウス操作そのものの自動試験
- 物理インストーラ操作
- 全DPI / theme組み合わせ
- 将来のYMM4バージョン互換
