# 選択配置

YMM4 Timelineで対象を選び、Pluginの［選択配置］を開きます。表情一覧の行選択は対象ではありません。

1. 配置関係を選ぶ。
2. その関係のPresetと、Libraryに登録した単一Item Templateを選ぶ。
3. 条件を変える場合はPresetの編集を開き、保存する。
4. ［予定を確認］でFrame / Length / Layerを確認する。
5. ［選択対象へ配置（追加）］を押す。既存Itemは削除・移動・短縮されません。

予定確認は読み取り専用です。配置時には最新Timelineで再計算します。対象の移動や追加などがあった場合は、予定をもう一度確認してください。実際の配置結果は下部に表示されます。配置はYMM4のUndo 1回で戻せます。

## 対象に合わせる（Target Companion）

Itemを1つ選択します。

- 開始 = 対象の開始 + 開始offset
- 終了 = 対象の終了 + 終了offset

開始offsetを負にすると手前へ、終了offsetを正にすると後ろへ延長します。0/0なら対象と同じ範囲です。

## 基準点を強調（Point Emphasis）

Itemを1つ選択します。基準点は開始 / 25% / 50% / 75% / 終了の5つです。

- 基準点 = 対象の開始 + floor(対象Length × 割合)
- 開始 = 基準点 + 開始offset
- 長さ = 固定長

割合の端数frameは切り捨てます。終了は最後に表示されるframeではなくexclusive endです。Frame 100、Length 40の終了は140です。

## 選択範囲を覆う（Selection Range）

2つ以上のItemを選択します。

- 開始 = 選択Itemの最も早い開始 − 開始前の余白
- 終了 = 選択Itemの最も遅い終了 + 終了後の余白

余白は0以上のframe数です。範囲全体へ1つだけ追加します。選択順ではなく実際の開始・終了を使います。中間に始まる長いItemが最後まで伸びている場合も、その終了を含みます。

複数Characterを含む範囲へ共通の飾りを置くなら、Characterを持たないTemplateを使います。Character付きTemplateを別Characterへ自動で書き換えて流用しません。

## 2Itemの境界（Boundary）

2つだけ選択します。2件選択時に候補として表示され、［予定を確認］または配置で条件を検証します。

1. 開始Frameが小さい方をA、大きい方をBとする。同じ開始Frameなら前後を決めず停止する。
2. `abs(A.End − B.Start) <= 許容差` を確認する。許容差0なら、隙間も重なりもない境界だけ。
3. **基準位置はAの終了（exclusive end）**とする。
4. 開始 = 基準位置 + 開始offset、長さ = 固定長。

初期Presetは開始offset −15、固定長30、許容差0で、境界の前後15frameを覆います。許容差を増やして小さな隙間や重なりを許容しても、基準はA.Endのままです。中間点へ動かしません。

条件が成立しないとき、近くの別Item・別のカットは検索しません。3つ以上の選択から勝手に2つを選ぶこともありません。

## 共通の制約

単位はframe。負の開始、長さ0以下、整数範囲外、空きLayerなし、Template参照切れ・曖昧参照では追加前に停止します。Layer範囲は優先Layer、より大きい番号、最小から優先直前の順に探索します。候補の全Lengthを確認します。

Characterを持つTemplateとCharacter関連TargetのCharacterが違う場合は停止します。Characterを書き換えて流用しません。

同じ関係に複数Presetを保存できます。最後の1つは削除できません。未保存の編集があれば配置・他Presetへの切替を停止します。［編集を戻す］は保存済み条件へ戻す操作です。

古いPlugin設定は、新しく追加されたProfileの初期Presetだけをメモリ上で補います。既存の名前・条件・選択Presetは保持し、読み込みだけで元ファイルを書き換えません。元から存在するはずのProfileが欠けている場合や未知の版は、自動修復せずエラーにします。

選択配置は独立Itemの追加で、軽い関連付けタグを新設しません。コピー元に関連付けがあれば生成cloneからだけ外します。v0.4の手動再同期は表情一覧からVoiceに関連付けた表情専用です。Quick Dropも関連付けなしです。

各機能の実YMM4検証結果はW9〜W11のNative Checkpointを参照してください。本文は使い方と数値の意味を定義し、検証結果そのものの代わりにはなりません。
