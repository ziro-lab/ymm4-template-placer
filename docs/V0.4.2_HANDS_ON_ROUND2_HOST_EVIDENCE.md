## L1 — Tool group

Use:

```csharp
YukkuriMovieMaker.Resources.Localization.Texts.ToolGroupUtilityName
```

The exact en-US host resolved it to `Utilities`, the same parent as Explorer / Browser / Plugin Portal / Notepad.

Literal Japanese `ユーティリティ` created a different group on that host. Do not hard-code display text.

## L2 — Preview refresh

- direct `Timeline.CurrentFrame` write emits `PropertyChanged(CurrentFrame)`;
- `TimelineViewModel.ScrollFrame(int)` did not change CurrentFrame and is only Timeline viewport scrolling;
- no dedicated public Plugin-facing "force current preview redraw" route was established by the broad public-surface scan.

Boundary: pixel-level repaint was not proved either way. Product code must not claim a forced-refresh capability from this evidence.

## L3/L4 — Item vs blank Timeline

Real OS-injected input on exact host:

- Item pointer route begins at `TimelineItemView`;
- blank Timeline pointer route begins at a TimelineViewModel-backed Grid;
- blank click changed CurrentFrame while preserving the existing selected Item;
- re-clicking an already selected Item re-fired Timeline `SelectedItems` changing/changed notifications even though the effective selection value was the same.

Implication: selection emptiness is not a generic-time-click signal. Selected-item re-click is observable.

## L5 — ruler / drag / keyboard / playback

- ruler route is TimelineScaleViewModel-backed;
- ruler click and ruler drag move CurrentFrame;
- Right keyboard navigation moves CurrentFrame;
- Space playback produces continuous CurrentFrame changes.

Therefore `CurrentFrameChanged` must never be the palette-switch trigger.

## Production boundary

Public plumbing used by the lab:

- WPF InputManager / routed pointer events
- Timeline property notifications

YMM4 visual-tree classification names are version-specific host structure. Production must:

1. recognize only bounded known routes;
2. fail safe by keeping the current palette for unknown routes;
3. keep a selection-notification fallback for Item selection;
4. never infer a time click from CurrentFrame change alone.
