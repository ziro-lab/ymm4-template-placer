# Behavior Preview Acceptance

Status: **P0 ACTIVE**

## P0 — Description Projection

P0 is accepted when:

1. Targeted Settings expose one typed `PlacementBehaviorDescription` covering the current finite placement vocabulary.
2. Generic Settings expose the same projection family for current Generic layer behavior.
3. `このセットの動き` is generated from that projection rather than a separate meaning implementation.
4. Existing Summary wording/meaning remains unchanged for accepted current cases.
5. Incomplete numeric Draft text remains visible/projectable and is never replaced by an invented value.
6. The projection performs zero Timeline mutation and no host/source resolution.
7. Focused, Checkpoint and Release lanes require `BEHAVIOR_PREVIEW_P0=PASS`.

## P1 — Read-only Preview

P1 is accepted when:

1. Preview renders from the current `PlacementBehaviorDescription`.
2. Target, anchor, alignment, duration and layer policy are visually distinguishable.
3. Neighbor/fallback is visible only when semantically relevant.
4. Generic and Targeted rules use one bounded visual vocabulary where their concepts overlap.
5. Preview reads the current staged Draft; opening/viewing Preview performs zero Settings/Timeline write.
6. Invalid/incomplete Draft input is shown as incomplete rather than normalized or replaced.
7. Preview has no drag/edit gestures and no independent placement calculation.
8. Compact Settings remains usable at narrow and normal Tool widths.

## P2 — Hands-on closeout

Before moving to the checklist:

- verify comprehension in real YMM4 without explanatory documentation;
- compare text Summary and schematic for the same Draft;
- verify the Preview does not crowd the high-frequency compact Settings path;
- decide final placement above/beside/below Summary from Hands-on evidence rather than pre-freezing layout.

The checklist starts only after the read-only Preview vocabulary is accepted.
