## WUX8-WUX13 outcomes

### WUX8 — Resume Continuity

Same-session Tool close/reopen resumes exact unchanged unfinished work across native ViewModel replacement. Expression assignments, Expression/Selection drafts, Palette drafts, add-task multi-selection and Template-management inputs are restored only when their original targets/registrations remain exact. Changed Voice/source targets are skipped rather than guessed. Resume itself writes neither Timeline nor settings.

### WUX9 — Bulk Palette Add

Single and N-source addition use the same batch preflight/commit path. Native proof covers ten-source add, exact LibraryEntry reuse in another Palette, already-added disablement, selection preservation while filtering, one ambiguous/missing source causing whole-batch zero-write, linked-Character filtering and three-source Expression recovery without invented assignment.

### WUX10 — Palette Ordering

`PaletteDefinition.LibraryEntryIds` remains the source of truth. Dedicated drag handles and Up/Down fallback persist user order per Palette. Reordering one Palette leaves another Palette using the same Library entries unchanged. Character-expression candidate priority follows the user-defined Palette order. Quick Drop remains on normal row double-click.

### WUX11 — Safety & Intent

Rare destructive Palette delete and Library unregister actions show real consequences before the UI commits them. Cancel is byte-for-byte zero-write. Confirmed unregister truthfully reports and removes affected Palette memberships while preserving the native YMM4 Template and Timeline. `キャンセル`, `戻る`, `シーン更新` and local `一覧更新` are separated by effect.

### WUX12 — Identity Clarity

Duplicate Palette names remain legal but become distinguishable only on collision. Duplicate Expression aliases gain source-name context only where needed; unique names stay short. The final 360px evidence explicitly selects a duplicate alias so the collapsed ComboBox visibly shows the source-qualified name.

### WUX13 — Final Integration Gate

Packaging requires all prior core/Task UX stages plus WUX8-WUX13, W12 selector stability, three acceptance manifests, warning/error-clean builds and exact native-smoked DLL identity. Source and package artifacts are generated only after the full native lane passes.
