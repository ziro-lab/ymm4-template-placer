# v0.4.1 .ymme stable install-folder hotfix

## Problem

Older Candidate packages were created as flat `.ymme` archives while the outer file name contained the version:

```text
Ymm4TemplatePlacer-v0.3.1.ymme
├─ Ymm4TemplatePlacer.dll
└─ ...

Ymm4TemplatePlacer-v0.4.0.ymme
├─ Ymm4TemplatePlacer.dll
└─ ...
```

YMM4 may use the `.ymme` file name as the plugin directory when the archive has no stable top-level folder. This can leave multiple versions installed side by side instead of replacing the previous version.

The package itself did **not** contain an older plugin DLL. The duplication risk came from the archive layout / install-directory identity.

## Fixed layout

v0.4.1 packages must use this layout:

```text
Ymm4TemplatePlacer-v0.4.1.ymme
└─ Ymm4TemplatePlacer/
   ├─ Ymm4TemplatePlacer.dll
   ├─ Ymm4TemplatePlacer.deps.json
   ├─ DocumentFormat.OpenXml.dll
   ├─ DocumentFormat.OpenXml.Framework.dll
   ├─ README.md
   ├─ THIRD_PARTY_NOTICES.md
   ├─ provenance.json
   ├─ v04-acceptance.json
   ├─ ux-acceptance.json
   └─ ux-workflow-acceptance.json
```

The outer `.ymme` file remains versioned for download clarity. The **internal top-level folder is always `Ymm4TemplatePlacer`** so upgrades target one stable plugin directory.

`tests/PackageVerified.ps1` now rejects:

- a flat archive containing `Ymm4TemplatePlacer.dll` at archive root;
- payload files outside `Ymm4TemplatePlacer/`;
- missing or extra payload files;
- an archived DLL that differs from the native-smoked distribution DLL.

The generated provenance / package-checks record the stable install folder as well.

## One-time cleanup for older Candidate installs

If v0.3.x or early v0.4 Candidate `.ymme` files were previously installed, close YMM4 and inspect:

```text
YMM4/user/plugin/
```

If version-named folders such as these exist:

```text
Ymm4TemplatePlacer-v0.3.1/
Ymm4TemplatePlacer-v0.4.0/
Ymm4TemplatePlacer-v0.4.1/
```

remove those old **version-named Template Placer folders only** while YMM4 is closed. Then install the fixed v0.4.1 `.ymme`.

The intended resulting location is:

```text
YMM4/user/plugin/Ymm4TemplatePlacer/
```

Do not delete unrelated YMM4 plugins or user assets.

## Boundary

This hotfix changes packaging/install-folder identity only. It does not redesign placement, presets, Palette behavior, Timeline mutation semantics, workbook schema, or settings data.
