## Experimental preset detector boundary

Allowed:

- exact current `Character.TachieType` / YMM4 tachie plugin registry resolution;
- current CharacterParameter read-only context;
- fresh plugin-created FaceParameter;
- reflection over that FaceParameter’s own public properties/attributes;
- public YMM4 property-editor interfaces/methods;
- bounded created editor visual tree / public DataContext properties to enumerate choices;
- semantic before/after snapshot hashing of the fresh FaceParameter.

Not allowed:

- scanning all loaded assemblies for arbitrary Preset types;
- private field access;
- calling internal preset view models by name;
- UI Automation;
- fake mouse/keyboard events;
- mutating an existing Timeline expression during detection.

## Settings transaction sizing

Do not implement “autosave” as direct property writes into live settings.

Keep one Settings-session coordinator with:

- open baseline;
- working draft;
- latest committed fingerprint;
- one coalesced pending commit flag/state.

A successful auto-commit must not call the current `ResetIntentSettings()` path because that would destroy user navigation and the immutable session baseline.

Introduce a focused “accept committed state while preserving session” method instead.

## Managed expression association sizing

Do not overload `IntentAssociationTag` with fake palette/entry GUIDs.

Add a separate versioned preset-source tag.

Extract only the common exact managed-bundle discovery/removal seam required for source switching.

Existing Template Intent source validation remains unchanged.

## Excel and Resync boundary

Round 4 Preset source is intentionally smaller:

- Excel = Template-only;
- protected imported assignments block Preset mode;
- legacy Resync truthfully skips experimental preset-source associations.

Do not expand Excel schema during this round.

## Stop/review conditions

Stop before widening the implementation if it appears to require:

- per-plugin hard-coded adapters as the main design;
- private YMM4 preset state;
- arbitrary assembly reflection;
- UI Automation/fake input;
- persistent learned compatibility database;
- a new placement engine;
- a new Undo stack;
- destructive repair of expression associations;
- Excel schema redesign;
- replacing exact managed association with text/position matching;
- weakening settings-store digest/conflict protection.
