# v0.4.2 Hands-on Round 4 A/B/C — acceptance matrix

All items remain additive checkpoint/release acceptance. Earlier gates remain mandatory at Checkpoint/Release, while ordinary Focused development runs intentionally execute only the stable core plus current Round 4 checks. See `docs/VALIDATION_STRATEGY.md`.

## A. Voice operation and nested scrolling

- A1 opening a row expression ComboBox invokes the same authoritative Voice navigation command as row click.
- A2 row click and ComboBox-open never produce duplicate navigation for one input.
- A3 ComboBox remains open/usable after navigation.
- A4 opening then cancelling the ComboBox may leave the current Voice selected without changing expression content.
- A5 keyboard-open and mouse-open have equivalent Voice navigation semantics.
- A6 successful immediate expression apply can refresh Preview only through the existing latest-wins coordinator.
- A7 no new direct View-side Preview SeekAsync route exists.
- A8 inner template-list wheel scrolls the inner list while it can move in the requested direction.
- A9 inner list at the requested edge passes further wheel movement to outer Settings.
- A10 wheel outside the inner list scrolls outer Settings.
- A11 scrollbar dragging remains functional.
- A12 nested wheel handling does not globally swallow unrelated wheel input.
