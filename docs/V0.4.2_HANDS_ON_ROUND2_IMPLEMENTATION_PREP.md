## Context consumption ordering

For Item pointer:

1. observe/classify pointer origin;
2. record pending Item intent;
3. allow YMM4 to process input;
4. on Timeline selection notification, read the post-host selection;
5. if non-empty, enter Selection context;
6. consume/clear pending intent.

For blank/ruler:

1. observe/classify pointer origin;
2. enter Generic once;
3. ignore subsequent CurrentFrame churn.

For unknown:

- clear no valid state;
- do not auto-switch based on CurrentFrame.

## Expression single-click ordering

Use row pointer/selection handling that does not mark ComboBox input handled.

```text
click row

 -> ComboBox still opens/changes normally when click target is ComboBox
```

Re-click of the same row should still be able to navigate if needed.

## Stop conditions

Stop implementation instead of widening scope if any of these becomes necessary:

- private/internal Preview APIs;
- custom Undo history;
- new rule DSL;
- replacing QuickDrop with a second generic placement engine;
- arbitrary visual-tree reflection;
- destructive migration of Round 1 settings;
- core relation rewrite solely to support the new UI.

If a stop condition appears, document the exact blocker and retain the last native-green checkpoint.
