# YMM4 Template Placer

YMM4で登録したテンプレートを、**「どこに・どの長さで・どのレイヤーへ置くか」まで含めて、少ない操作で繰り返し配置するためのTool Plugin**です。

YMM4標準のテンプレートを元にして、タイムライン上の対象や現在の再生位置に合わせて配置します。

```text
タイムラインで対象を選ぶ
        ↓
必要ならセットを切り替える
        ↓
使いたいタイルをクリック
        ↓
保存してある配置関係で自動配置
```

このリポジトリはソースコードと開発状況の公開用です。配布版は作者が案内する公式配布先から取得してください。

> YMM4本体とは別に開発している非公式プラグインです。

## できること

- **対象に合わせたテンプレート配置**  
  選択中のアイテムの開始・終了・中央、選択範囲、境界などを基準に、あらかじめ保存した関係でテンプレートを配置できます。

- **再生位置への汎用配置**  
  タイムラインの現在位置を基準に配置できます。指定レイヤーが埋まっている場合は、配置しない・上方向を探す・下方向を探す、といった有限のルールを設定できます。

- **複数アイテム入りテンプレート**  
  テンプレート内の時間差・レイヤー差・長さを保ったまま、ひとまとまりとして配置できます。

- **セットとタイルによる整理**  
  用途ごとにセットを作り、よく使うテンプレートをタイルとして並べられます。表示名・色・形・並び順も変更できます。

- **固定列と位置ショートカット**  
  タイルを固定列で並べ、画面上の位置にショートカットキーを割り当てられます。通常の文字入力などを邪魔しない範囲で動作します。

- **配置の簡易設定とPreview**  
  対象アイテム用Setでは、開始・中央・終了、対象/テンプレート長、1段上/下といった頻出の配置変更を、通常設定と同じ設定データへその場で反映できます。配置Previewも同じ設定から表示します。

- **曖昧な周囲候補の安全な再実行**  
  同順位の周囲候補が複数でも最終結果が同じならそのまま配置します。結果が複数に分かれる場合は1回目を0書込みで止め、同じ状態で2回目を実行した時だけ各結果をまとめて配置します。

- **「表情をまとめて」**  
  シーン内のVoiceを一覧表示し、表情テンプレートまたは対応する立ち絵Pluginの表情プリセットから関連する表情を配置・置換できます。必要な表情プリセットはSetへ登録し、通常の配置タイルとして使うこともできます。Voiceを選ぶと再生位置やPreviewの同期も行います。

- **Excelによる一括編集**  
  表情の割り当てをExcelへ書き出し、まとめて編集して読み戻す補助経路があります。

- **YMM4標準Undo/Redo**  
  配置はYMM4のUndo/Redoで戻せるようにしています。

## 基本的な使い方

### 1. YMM4へテンプレートを登録

繰り返し使いたいアイテムを、まずYMM4標準のテンプレート機能へ登録します。

Template Placerはそのテンプレートを参照し、配置時に独立したコピーを作ります。元テンプレートの中身を別のデータベースへ複製する方式ではありません。

### 2. セットを作る

Template Placerの「設定」で、用途ごとのセットを作成します。

対象となるアイテムの種類やキャラクター、配置位置、長さ、レイヤーなどを設定し、そのセットで使うテンプレートを追加します。

### 3. タイムラインで対象を選ぶ

アイテムを選ぶと、その状況に対応するセットが表示されます。

タイムラインの背景や時間位置を基準にした汎用配置も利用できます。

### 4. タイルを押す

使いたいテンプレートのタイルをクリックすると、保存した配置関係に従って配置します。通常の再クリックは追加配置です。ただし周囲候補から複数の最終結果が出る場合だけ、1回目は確認で止まり、同じ状態の2回目で候補ごとの結果をまとめて配置します。

より詳しい操作方法は [docs/USAGE.md](docs/USAGE.md) を参照してください。

## インストール

配布されている `.ymme` をYMM4へインストールし、YMM4を再起動します。

インストール後は、Toolメニューの「ユーティリティ」グループから **YMM4 Template Placer** を開きます。YMM4の表示言語によってグループ名は変わる場合があります。

Template Placerの固定インストールフォルダは次の場所です。

```text
YMM4/user/plugin/Ymm4TemplatePlacer/
```

設定ファイルはYMM4フォルダと一緒に持ち運べるよう、プラグインの `Data` フォルダへ保存します。

```text
YMM4/user/plugin/Ymm4TemplatePlacer/Data/settings-v04.json
```

旧バージョンの `%LOCALAPPDATA%/Ymm4TemplatePlacer/settings-v04.json` だけが存在する場合は、内容を検証してから初回起動時にPortable側へ移行します。旧ファイルは自動削除せず、バックアップとして残します。Portable側が存在する場合はそちらを常に正として使い、旧LocalAppData側の内容が異なっていてもPortable側を優先します。

更新前や大きな設定変更を行う前は、普段のYMM4プロジェクトと設定をバックアップしておくことをおすすめします。

## 安全性について

通常の配置では、**既存アイテムを勝手に移動・短縮・削除して空きを作ることはありません**。

配置前に必要なテンプレートや配置先を確認し、必要な条件を満たせなければ、その操作では何も書き込みません。曖昧な参照先を名前や位置から推測して選ぶこともしません。

「表情をまとめて」で既存の表情を置き換える場合も、Template Placer自身が管理していることを厳密に確認できた関連アイテムだけを対象にします。手動で置いた表情や無関係なアイテムを推測して削除しません。

## 検証環境

主な回帰検証環境は次のとおりです。

| 項目 | 環境 |
| --- | --- |
| OS | Windows |
| YMM4 | 4.55.1.1 Lite |
| .NET | 10 |
| UI | WPF |

実際のYMM4を起動するWindows Nativeテストで、配置、Undo/Redo、設定、UI操作、パッケージ構造などを継続的に検証しています。
